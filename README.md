# ssat-vocab-tool

A tool to help you remember words for the SSAT.

## Features

- View all 36 words from Sets 15, 16, and 17
- Search for a word and see its definition and set number
- Search ignores capital letters and extra spaces
- Exit the program from the menu
- Invalid menu choices show a message instead of crashing

## File Structure

- `main.py` — where the code goes
- `words.csv` — where I store the words
- `README.md` — the instruction book
- `.gitignore` — the files GitHub should ignore

## Setup

git clone https://github.com/GeorgeFu77/ssat-vocab-tool.git
cd ssat-vocab-tool

## Sample Interaction

View all words, 2) Search, 3) Exit: 2
What word do you want to search? drab
Word: drab
Definition: to be dull or cheerless
Set: 15
